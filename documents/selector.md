# 意味のあるセレクタ

## [data-app-element-drag-and-drop]

ドラッグアンドドロップによるファイル指定

ドラッグアンドドロップするエリアに設置する

```
{
  target: string;
  info: string;
  dragover_class: string;
}
```

## [data-app-element-postal-code]

郵便番号検索

検索ボタンに設置する

```
{
  postal_code: string;
  prefecture: string;
  city: string;
  address_line1: string;
}
```
